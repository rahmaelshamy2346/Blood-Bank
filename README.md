# Blood Bank Database

A simple Blood Bank Management System built using SQL and MySQL.

## Project Overview

This project is designed to manage blood donors, blood bags, hospitals, and blood requests in a blood bank system.

## Database Tables

The database contains four main tables:

* **Donors** – Stores donor information such as name, blood type, donation date, and contact number.
* **Blood_Bank** – Stores information about available blood bags, including blood type, expiration date, and storage location.
* **Hospital** – Stores hospital information such as name and city.
* **Blood_Request** – Records blood requests from hospitals and connects hospitals with blood bags using foreign keys.
